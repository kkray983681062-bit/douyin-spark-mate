# 功能与使用说明

## 好友和群聊选择

同步抖音网页可读取的已有单聊和群聊，按稳定会话 ID 与类型区分同名对象。群聊显示「群聊」标识；有火花的会话优先，数字天数越多越靠前。支持昵称或群名搜索、整行勾选、全选当前列表及取消全部；过滤列表不会清除已勾选的其他会话。

同步保留已有的勾选和专属消息，新同步的群聊默认不勾选。只向本人勾选的好友或已有群聊发送。0.1.5 升级后需再点击「同步好友」，群聊才会进入本地列表；原有好友、设置和发送记录保留。

群聊修复已包含在 0.1.7 中；旧版 0.1.5 不包含此功能。

## 消息和模板

| 内容 | 使用方式 | 当前发送路径 |
| --- | --- | --- |
| 文字 / emoji | 输入文字，使用常用按钮或系统输入法添加 emoji | 已登录 IM SDK |
| 图片 / GIF | 导入 PNG、JPG、WebP 或 GIF，本机保存素材副本 | 抖音聊天页 |
| 抖音原生表情 | 先选好友或群聊，再读取网页表情面板中已加载的可用表情 | 抖音聊天页 |

统一消息用于没有专属内容的会话；可给每位好友或每个群聊保存独立内容，也可保存多个常用模板。文字单条最多 1000 字；图片限制为 20 MB 以内，超大尺寸或无效文件会提示重新选择。

读取原生表情不会执行发送。网页可用表情不一定覆盖手机 App 的全部收藏；GIF 是否呈现动画，以平台实际收到的内容为准。

## 发送与状态

一键发送采用串行队列，默认在不同收件人之间保留短间隔。文字 / emoji 直接使用已登录的私信模块，无需打开每个好友的聊天记录；首次初始化仍需要网络连接和有效登录。

- **已发送**：取得与本次消息相符的服务端确认。
- **待确认**：发送已触发，但缺少可靠回执。请先核对聊天记录，当天不会自动重发。
- **失败**：发送前出错，或平台明确拒绝；按提示处理后再操作。
- **已跳过**：当天已经发送，或已有结果不明、尚在处理的任务。会保存本轮的好友昵称 / 群名与具体原因。

发送记录支持按轮次和结果筛选。想查看本轮跳过的人，打开“发送记录”，选择对应轮次，再选择“只看已跳过”。全部轮次显示最近 200 条；选定一轮可查看完整明细。轮次下拉框列出最近 50 轮。

跳过不会覆盖好友的“今日已发送”状态，也不会删除原来的成功回执。0.1.5 起保存每轮跳过明细；旧版没有保存的明细不会自动补造。

日期按北京时间计算，记录时间按软件界面显示。点击停止后不再开始后续收件人；已在发送的消息可能已经到达平台，不能保证撤回。软件不根据本地发送成功推断火花必然点亮。

## 慢网、窗口与账号

同一账号的登录、同步和发送复用官方网页窗口。等待过程显示进度，可点击停止；超时、失败和停止后保留窗口，方便继续加载。切换账号会关闭原账号页面并创建独立会话；关闭软件或忘记当前会话的登录也会关闭对应窗口。

验证码由本人完成。账号不匹配或登录失效时停止任务；发送期间不要切换账号。图片和原生表情发送期间也不要切换聊天页。

## 多账号切换（0.1.7 起）

1. 点击左侧 **添加账号**，在新的会话中扫码。每个账号首次添加都需要本人登录。
2. 从左侧下拉框选择已保存账号。软件恢复登录、打开私信并核对服务端和私信账号；成功后才更新当前账号及其联系人列表。
3. 点击 **管理账号** 可修改备注、为所选账号重新扫码或忘记登录。相同备注也会显示不同账号标识末六位，便于区分。

同一时间只操作一个账号。各账号的好友和群聊、勾选、专属内容、编辑草稿、模板、发送历史和当天去重相互隔离。同一账号重新扫码更新原有档案，不另建一套去重记录。重新扫码时若登录了别的账号，会停止并保留原登录；添加别的账号请使用“添加账号”。

发送、同步或登录中无法切换；可先停止，等当前结果记录完成后再切换。取消或核对失败不会改变当前账号，也不会自动发送。登录失效只影响对应账号；临时网络故障可以重试。切换仍需网络加载和核对，不保证瞬间完成或登录永久有效。

升级时沿用旧版当前账号的配置和历史，并将旧登录文件转入独立账号存储。多账号登录由 0.1.7 管理，旧版不支持读取此结构。忘记登录仅删除所选账号的本机登录文件，保留联系人、模板和历史；以后用同一账号扫码可继续沿用。

## 当前范围

提供手动启动的一键发送，不含定时任务、关机发送或无人值守服务。文本接口仍依赖浏览器中的已登录 IM SDK。软件适配的是抖音当前网页，网页更新后可能需要维护。
