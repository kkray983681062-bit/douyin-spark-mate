# 隐私与公开内容

## 本机保存的数据

数据目录为 `%LOCALAPPDATA%\SparkMate`：

| 内容 | 文件 / 目录 | 处理方式 |
| --- | --- | --- |
| 登录状态 | `login.dpapi` | 使用当前 Windows 用户的 DPAPI 加密 |
| 好友、模板、发送记录 | `spark-mate.db` 及 SQLite 配套文件 | 本地数据库，按账号区分；不等同于加密数据库 |
| 导入的图片 | `media` | 保存本机副本，原文件移动后仍可使用 |

软件不把这些内容上传到开发者服务器。扫码、同步和发送会访问抖音服务，加载头像等资源会访问相应 CDN。官方页面及内置浏览器遵循其各自的数据处理方式。

退出登录删除本机登录凭据，保留好友配置、模板和历史。常规卸载保留用户数据。软件单实例运行，以减少重复操作。

## 开源和发行包的范围

公开内容包括运行源码、构建脚本、许可证、使用说明、虚构测试数据和演示截图。公开截图只使用模拟联系人。

以下内容不进入仓库或发行包：真实 Cookie / Token、登录态、运行时数据库、联系人和聊天记录、真实账号截图、开发浏览器资料、诊断抓取文件、开发日志、本机绝对用户路径。

发行前检查公开文件列表、敏感模式和本机真实数据值的匹配，并检查安装包内容和压缩包。检查结论用于说明本次发布范围，不代替使用者对自己的日志和截图进行处理。

## 提交问题前

不要上传 `login.dpapi`、`spark-mate.db`、浏览器存储文件或完整应用数据目录。截图请遮住本人和好友的昵称、头像、抖音号、私信内容、二维码和登录提示中的个人信息。

复现问题通常只需要：软件版本、Windows 版本、操作步骤和去除个人信息后的错误提示。不要在公开 Issue 中提交账号凭据。
